# Velora Travels ✦ Crafting Journeys Since 2018

A responsive, multi-page travel agency website that promotes destinations, tour packages and services.

## 🎯 Overview

**Velora Travels** is a fictional Sri Lanka-based travel agency. The website helps visitors explore destinations, compare tour packages and get in touch to plan their trip.

### Target Audience
- Couples looking for romantic getaways
- Families planning group holidays
- Solo travellers and adventure seekers
- Luxury travellers who want fully curated trips

### Goals
- Give visitors an easy way to browse destinations and tour packages
- Build trust through the company story, values and team
- Make it simple to contact the agency and request a custom trip

---

## ✨ Features

- **Home** – hero section, key stats, featured destinations, popular packages, guest testimonials and a call-to-action
- **Destinations** – destination cards with region filter buttons (Asia, Europe, Africa, America, Middle East)
- **Packages** – tour package cards showing duration, group size, rating, price and a Book Now button, plus a custom package request section
- **About Us** – company story, core values, team members and company statistics
- **Contact** – enquiry form with a travel interest dropdown, office details, opening hours and social links
- Newsletter sign-up and consistent navigation and footer on every page
- Fully responsive layout for desktop, tablet and mobile

## 🚀 Run It Locally

1. Clone the repository:
   ```
   git clone https://github.com/hafsa081204-oss/velora---travels.git
   ```
2. Open the project folder:
   ```
   cd velora---travels
   ```
3. Double-click `index.html` to open it in your browser (or use the **Live Server** extension in VS Code).
